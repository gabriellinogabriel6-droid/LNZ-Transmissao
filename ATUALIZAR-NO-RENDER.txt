LNZ TRANSMISSÃO - ATUALIZAÇÃO

1) No GitHub, substitua estes arquivos/pastas pelo conteúdo desta versão:
   - server.js
   - package.json
   - public/
   - README.md
   - .env.example (opcional, serve de referência)

2) Faça Commit changes.

3) No Render, abra o Web Service.

4) IMPORTANTE - BANCO DE DADOS:
   Crie um PostgreSQL no Render e copie a Internal Database URL.
   Em Web Service > Environment, crie:
   DATABASE_URL = URL_INTERNA_DO_POSTGRES

5) Mantenha também, se já usa:
   DISCORD_URL=https://discord.gg/m67kQeZrns
   FEEDBACK_WEBHOOK_URL=seu_webhook (somente no Render)

6) Faça Manual Deploy > Deploy latest commit, caso não inicie sozinho.

7) Quando aparecer Live, abra o site. Se o navegador estiver em versão antiga, o próprio site mostrará o botão Atualizar agora.

NOVIDADES:
- Login obrigatório.
- Usuário único no banco.
- Senha protegida por hash.
- Sessão persistente.
- Aviso de atualização/queda.
- Várias pessoas podem transmitir a tela ao mesmo tempo.
- Cada transmissão aparece separada e tem controle de som para quem assiste.

RECUPERACAO DE CONTA
- A nova versao adiciona codigo de recuperacao para troca de senha.
- Nao precisa criar tabela manualmente: o servidor atualiza a tabela users sozinho.
- Confirme que DATABASE_URL esta configurado no Render.
- Depois do deploy, usuarios antigos devem entrar na conta e clicar em "Gerar novo codigo de recuperacao" uma vez.

CORREÇÃO PERFIL / AMIGOS / COR DO SITE
- Substitua server.js
- Substitua public/app.js
- Substitua public/index.html
- Substitua public/style.css
- Faça Commit changes e Deploy latest commit no Render.
- Depois abra o site com Ctrl + F5.


PAINEL ADMIN PRIVADO
- No Render > Environment, adicione:
  ADMIN_USERNAME=SEU_LOGIN_EXATO
- Exemplo: ADMIN_USERNAME=lino
- Somente essa conta, autenticada no site, consegue abrir /api/admin/dashboard e o Painel Admin.
- O painel mostra contas cadastradas, usuários online, sessões, salas ativas, transmissões, feedbacks e registros de atividade.
- Senhas, códigos de recuperação e conteúdo das mensagens do chat NÃO aparecem nos logs.


TUDO SALVO NA CONTA
-------------------
Confira no Render > Environment se DATABASE_URL está configurado com o PostgreSQL. Sem isso, contas/perfis persistentes não funcionarão.
